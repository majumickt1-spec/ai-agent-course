# 空白設定範本

[回教學](../GUIDE.md)

本目錄只是教材。範本刻意使用 `.template.md`，避免被當成課程儲存庫的即時指令。

先建立自己的 codex_agent 資料夾，再依下表複製並改名。目標已存在時先比較，保留自己的設定。把方括號提示改成自己的資料，不確定的留「待確認」。

| 下載檔 | 放到自己專案的哪裡 |
|---|---|
| [AGENTS.template.md](AGENTS.template.md) | 根目錄 `AGENTS.md` |
| [CORE_RULES.template.md](CORE_RULES.template.md) | `000_Agent/CORE_RULES.md` |
| [MEMORY.template.md](MEMORY.template.md) | `000_Agent/memory/MEMORY.md` |
| [DESIGN.template.md](DESIGN.template.md) | 根目錄 `DESIGN.md`，做視覺內容才需要 |
| [gitignore.template](gitignore.template) | 根目錄 `.gitignore`，確認不是 `.gitignore.txt` |

不用寫指令也可以：把需要的範本附到 Codex，請它「按表格放到我的個人專案；先讀現有檔案，不覆蓋」。完成後按教學第 05 步開新對話驗證。
