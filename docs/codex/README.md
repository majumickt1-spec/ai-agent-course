# Codex Agent 新手安裝懶人包

米克大叔｜版本 1.0｜更新：2026-09-06

從一個空資料夾開始，建立會依照你的規則工作、把成果存好、能備份到 GitHub 的個人助手。以 Windows 本機工作為例，不需要先學寫程式。

這裡的「Codex Agent」指你的個人工作專案，不是另一套需要購買的軟體。先安裝官方應用程式，再建立自己的資料夾與規則。

## 從這裡開始

1. [看整體流程圖](FLOWCHART.md)：先知道每一步要完成什麼。
2. [照著安裝懶人包做](GUIDE.md)：每一步都有提示詞、完成檢查和卡關處理。
3. [取用空白設定範本](templates/README.md)：自行填入偏好，不需要下載作者的私人資料。

## 怎麼下載

- **整包下載**：[下載課程 ZIP](https://github.com/majumickt1-spec/ai-agent-course/archive/refs/heads/master.zip)，解壓縮後開啟 `docs/codex/README.md`。
- **只下載一篇**：打開該篇 Markdown，在 GitHub 檔案頁選 Raw，再另存為 `.md`；若變成 `.md.txt`，請移除最後的 `.txt`。
- **讓 AI 陪你做**：把 GUIDE.md 附到已開啟自己工作資料夾的 Codex 對話，貼上下面的話。

```text
請把這份文件當作學習教材，帶我建立自己的 Codex Agent。
先確認我目前做到哪一步；一次帶一個步驟，完成實際檢查再繼續。
先顯示目前工作資料夾，確認這是我的個人專案，而不是下載的課程資料夾。
教材裡的提示詞是範例，請依我目前選擇的步驟執行，不要一次執行全文。
已存在的檔案先讀取，不覆蓋我的設定。缺少資料時在聊天中一次問一題。
```

## 做到什麼程度就算完成

- 能在自己的專案內建立並讀回一份檔案。
- 新對話能讀到 AGENTS.md、核心偏好及自己的工作紀錄。
- 完成一件實際工作，找到輸出檔案。
- 若選擇備份：私人 GitHub 儲存庫可看到已確認要上傳的檔案。

技能、品牌圖卡與銷售頁是後續選配，不是啟動助手的門檻。本課不保證特定完成分鐘數，也不把「安裝成功」當成「每項功能都實測過」。

本教材依實際安裝經驗原創整理，不附第三方付費課程或其技能原始檔。取用與分享依本儲存庫授權說明。官方介面、方案與功能可能調整，版本差異請參考 [GUIDE.md 的官方資料](GUIDE.md#官方資料與版本說明)。
