# 1-1 安裝配置你的 Claude Code

## 為什麼要學這個

在你有一個「懂你、記得你」的 AI agent 之前，你需要先有一個能長期對話、長期記憶的工具。如果只是用網頁版 AI 聊天，每次開新對話都要重講一次自己是誰——那不是 agent，只是問答機。

Claude Code 是能讀你電腦裡的檔案、記住你設定的規則、並且持續累積記憶的工具，是打造 AI agent 的地基。

## 你會學到什麼

- 把 Claude Code 裝到你的電腦上
- 用你的帳號登入，確認可以正常對話
- 知道待會 AI agent 的所有東西，都會放在哪個資料夾裡

## 步驟

1. 前往 Claude Code 官方安裝頁面，依照你的作業系統（Windows / Mac）下載安裝檔
2. 執行安裝檔，一路下一步完成安裝
3. 打開 Claude Code，選擇「登入」，用你的 Anthropic 帳號登入（沒有帳號的話，先去 claude.ai 免費註冊）
4. 登入成功後，隨便打一句話測試，例如：「你好，你現在可以正常回覆我嗎？」
5. 確認 AI 有正常回覆你

## 常見卡關

| 狀況 | 解法 |
|---|---|
| 安裝檔打不開 / 被防毒軟體擋 | 確認是從官方頁面下載的，暫時允許防毒放行 |
| 登入畫面一直轉圈 | 檢查網路連線，重開一次程式 |
| 忘記帳密 | 用 claude.ai 頁面的「忘記密碼」重設 |

## 動手練習

打開 Claude Code，跟它說：「幫我確認你現在讀取的工作資料夾路徑是哪裡。」把它回覆的路徑記下來——這個資料夾，之後就是你 AI agent 的家。

## 完成檢查

- [ ] Claude Code 已安裝在電腦上
- [ ] 能正常登入、正常對話
- [ ] 知道 AI 目前的工作資料夾在哪裡
