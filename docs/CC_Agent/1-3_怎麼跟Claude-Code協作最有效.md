# 1-3 怎麼跟 Claude Code 協作最有效

## 為什麼要學這個

很多人用 AI 卡關,不是因為 AI 不夠聰明,而是「丟關鍵字」而不是「描述場景」。AI 沒有讀心術,你講得越具體,它幫你做對的機率越高,你要重做的次數就越少。

## 你會學到什麼

- 分辨「丟關鍵字」跟「描述場景」的差別
- 一個能重複套用的下指令公式
- 讓 AI 先確認理解、再動手做的習慣

## 步驟

### 對比：丟關鍵字 vs. 描述場景

**丟關鍵字（容易做錯）**
> 「幫我寫日記功能」

**描述場景（AI 才知道要做什麼）**
> 「我想要每天晚上結束工作時,能打一句話讓你問我幾個問題,幫我整理成一篇日記,存到固定的資料夾裡,並且問我要不要推上 GitHub。」

### 下指令公式

```
情境（什麼時候會用到）
＋ 目標（你想要什麼結果）
＋ 限制（有什麼不能做 / 一定要照做的規則）
```

範例:
> 情境:我每天結束工作想回顧一下
> 目標:幫我整理成一篇日記檔案
> 限制:用繁體中文,存到 journals 資料夾,不要幫我亂加內容

### 讓 AI 先確認理解

如果任務比較複雜,先跟 AI 說:「先不要動手,你先跟我確認你理解的步驟是什麼。」
等 AI 講出它的理解沒問題,再說:「可以,開始做。」

這樣可以避免 AI 做錯方向,重做兩三次。

### 怎麼跟 AI 說

跟它說：

> 「幫我讀一下 `docs/CC_Agent/1-3_怎麼跟Claude-Code協作最有效.md`，之後只要我下的指令太模糊，請你直接跟我說『你這樣講我不確定要做什麼，能不能補充情境跟限制』，幫我養成習慣。」

## 常見卡關

| 狀況 | 解法 |
|---|---|
| AI 做出來的東西跟想的不一樣 | 回頭檢查自己是不是只丟了關鍵字,補上情境和限制重講一次 |
| 講了很長一段但 AI 還是做錯 | 拆成更小的任務,一次只交代一件事 |
| 不確定 AI 有沒有真的聽懂 | 用「先不要動手,跟我確認你的理解」這句話 |

## 動手練習

挑一件你這週想請 AI 幫忙的事,用「情境＋目標＋限制」公式寫一次指令,實際下給 AI 看結果有沒有比較準。
