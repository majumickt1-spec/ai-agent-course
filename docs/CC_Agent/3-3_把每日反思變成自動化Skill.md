# 3-3 把每日反思變成自動化 Skill

## 為什麼要學這個

Phase 2 你已經讓 AI 會引導你寫反思了，但每次都要重新跟 AI 解釋一次流程還是很浪費。這一步要把它封裝成「打一句話，整套流程自動跑完」的 Skill。

## 你會學到什麼

- Skill 的組成：觸發詞、步驟、輸出格式、存放位置
- 怎麼把一個手動流程，變成可重複呼叫的自動化

## 步驟

1. 想清楚一個 Skill 需要的四個部分：

| 部分 | 說明 | 範例（日記 Skill） |
|---|---|---|
| 觸發詞 | 什麼話會啟動這個流程 | 「今天結束了」「寫日記」 |
| 步驟 | 每次都要照做的固定動作 | 逐題問問題 → 整理成文件 → 存檔 |
| 輸出格式 | 產出的東西長什麼樣子 | 固定標題結構的 Markdown 檔 |
| 存放位置 | 存到哪個資料夾、什麼命名規則 | `journals/日期.md` |

2. 跟 AI 說：「我想把『___』這件事變成一個 Skill，觸發詞是『___』，請幫我把整個流程寫成一份說明檔。」
3. 測試：開新對話，打觸發詞，確認整套流程能跑完

### 怎麼跟 AI 說

跟它說：

> 「幫我讀一下 `docs/CC_Agent/3-3_把每日反思變成自動化Skill.md`，然後幫我把『___（填入你想自動化的事）』設計成一個 Skill，包含觸發詞、步驟、輸出格式、存放位置。」

## 常見卡關

| 狀況 | 解法 |
|---|---|
| 一次想封裝太多流程 | 先做一個最常用、最簡單的，做熟了再做下一個 |
| Skill 跑到一半卡住 | 檢查步驟寫得夠不夠具體，AI 是照你寫的字面意思執行的 |

## 動手練習

挑一件你這週重複做超過 3 次的事，照上面四個部分寫成一個 Skill 草稿。

## 完成檢查

- [ ] 選好一件要自動化的事
- [ ] 寫出這個 Skill 的四個部分
- [ ] 實際觸發測試過一次，能跑完整套流程
