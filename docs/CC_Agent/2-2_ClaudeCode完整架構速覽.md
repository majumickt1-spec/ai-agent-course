# 2-2 Claude Code 完整架構速覽

## 為什麼要學這個

東西越做越多之後，如果沒有搞懂「什麼放哪裡」，資料夾會越來越亂，AI 也會越來越難管理。這一步幫你建立一張整體地圖，之後不管做什麼都知道該放哪。

## 你會學到什麼

- AI agent 系統的四個核心元件
- 每個元件各自負責什麼，彼此怎麼配合

## 步驟

### 四個核心元件

| 元件 | 角色 | 白話比喻 |
|---|---|---|
| `CLAUDE.md` | 規則書 | 新員工的教育訓練手冊 |
| 記憶資料夾 | 長期記憶 | 員工的工作筆記本，跨對話都記得 |
| Skills（技能） | 固定流程 | 員工學會的 SOP，一句話觸發整套動作 |
| 專案資料夾 | 產出物 | 員工實際做出來的成果，放檔案的地方 |

### 對照你自己的專案

打開你的專案資料夾，找找看：
1. 哪個檔案是你的 `CLAUDE.md`？
2. 有沒有一個資料夾是專門放「AI 記得的事情」？
3. 有沒有已經做好的 Skill（例如你可能已經做過的自動化流程）？
4. 平常產出的東西（草稿、成品）都放在哪裡？

## 常見卡關

| 狀況 | 解法 |
|---|---|
| 搞混 CLAUDE.md 跟 Skill 的差別 | CLAUDE.md 是「AI 永遠要遵守的規則」；Skill 是「特定任務的一套固定步驟」，兩者不衝突，是分層關係 |
| 不知道記憶資料夾在哪裡 | 問 AI：「我的記憶檔案存在哪個路徑？」它會告訴你 |

## 動手練習

畫一張（或寫一份清單）標出你目前專案裡，這四個元件各自對應到哪個檔案／資料夾。

## 完成檢查

- [ ] 能用一句話解釋 CLAUDE.md、記憶、Skill、專案資料夾各自的角色
- [ ] 知道自己專案裡這四樣東西分別放在哪
